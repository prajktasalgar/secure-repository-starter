
# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability
in this project, please report it privately
to the repository maintainer.

Do not publish passwords, API keys, or
sensitive information in public issues.

## Security Best Practices

- Never commit passwords or API keys.
- Keep dependencies updated.
- Run automated security scans.
- Review security findings before merging code.
- Use environment variables for sensitive information.

## Supported Versions

The current development version is the
version maintained by this repository.
